# atomicautomata

Fullscreen cellular automata controls for an assembly: the application, microscope,
and hardware working together.

Install [Deno](https://deno.com/), then run:

```sh
deno task start
```

Open [localhost:8080](http://localhost:8080). No separate dependency install is needed.
The browser loads the existing graphics libraries from the internet.
